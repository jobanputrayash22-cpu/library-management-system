# Library Management System

A simple Library Management System developed using Python, Tkinter and SQLite.

## Features

- Add books
- Delete books
- Add members
- Delete members
- Issue books
- Return books
- View issue and return records
- SQLite database
- Input validation
- Exception handling

## Technologies Used

- Python
- Tkinter
- SQLite

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in terminal.
4. Run:

```bash
python app.py
